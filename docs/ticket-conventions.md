# Ticket titles

`PRODUCT - TYPE - Title`, then the description on indented lines under it.

```
KAHF - ISSUE - Login returns 500 on second attempt #nov
  Repro: open /login twice in one session.
  Sentry: <link>. Expect: 200 and a fresh session.
```

Add to backlog on Pipelines takes this as is: each unindented line is one item, indented lines under it are its description (shown on the card, kept as task notes in the vault). End the title line with `#oct`, `#nov` or `#dec` to tie it to a checkpoint.

## PRODUCT (match the block)

KAHF · ALISHA · NIYYAH · ASSETFLOW · XARVIS · HOMELAB · CARWASH · CLICK · DISTRIBUTION · FNF · BODY · SOUL · FINANCE · OPS (cross-product)

## TYPE

| Keyword | Use for |
|---|---|
| ISSUE | Something is broken (a bug). Description: repro, expected, actual, link. |
| FEATURE | New capability users or you will get. |
| POC | Time-boxed experiment to answer a question. Description: the question and the exit criteria. |
| MEETING | Prep for or follow-up from a meeting. Description: who, agenda or decisions. |
| TASK | Concrete work with no open question. |
| IDEA | Not committed. Prefer the Notebook; use this when it must sit in the backlog. |
| RESEARCH | Reading or comparing before a decision. |
| DECISION | A choice to make; description lists the options. |
| CHORE | Upkeep: upgrades, cleanup, renewals. |
| BLOCKER | Something stuck. Prefer the Notebook, which links it to the cards it stops. |

Title: imperative or a plain noun phrase, under ~80 characters, no trailing full stop.
